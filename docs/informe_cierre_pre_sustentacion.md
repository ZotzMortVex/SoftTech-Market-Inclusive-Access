## 5. Cambios de comportamiento para el documento técnico

- El administrador fallback ya no se aprovisiona con una credencial fija: solo existe en memoria cuando se configuraron expresamente las credenciales de fallback.
- El Centro de Accesibilidad ofrece destellos `Apagado`, `Suave`, `Estándar` y `Vívido`. `Apagado` desactiva los pulsos; los avisos escritos siguen disponibles.
- La escala tipográfica se limita a 100–200 %, en pasos de 5 %; una entrada no finita vuelve al valor accesible predeterminado.
- Al 200 %, el checkout, historial y elementos relacionados se redistribuyen para evitar solapamientos y desbordamiento.
- Al cancelar o recibir una respuesta incompleta de Mercado Pago, el carrito se conserva y no se confirma un pedido. Los pagos pendientes tampoco crean un pedido confirmado.
- Al eliminar una cuenta cliente, se revocan sus sesiones MySQL y fallback; un error al revocar impide confirmar la eliminación.
- Se actualizaron las versiones resueltas de dependencias enumeradas en la sección 2.
- Brechas que requieren verificación manual: el esquema local revisado no tenía `password_reset_tokens`; falta validar correo SMTP real, recorridos de compra sandbox y accesibilidad con personas usuarias. No se hicieron migraciones ni compras.
- Se corrigió en el informe de revisión anterior la etiqueta de destello para reflejar el texto real `Vívido` (no `Intenso`).
